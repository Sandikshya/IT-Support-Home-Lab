# IT-Support-Home-Lab
A practical home lab documenting hands-on IT support, networking, troubleshooting, and Windows administration skills.

## About This Lab 

This project is designed to build practical skills relevant to entry-level IT Support, Desktop support and Service Desk Role.

The lab covers:

- Windows administration and troubleshooting
- Networking fundamentals
- Hardware and software troubleshooting
- User and permission management
- Active Directory fundamentals
- Device configuration and deployment
- Technical troubleshooting and support documentation

## Learning Approach
I am building this lab through practical exercises, simulated IT support scenarios and troubleshooting tasks rather than relying only on theoretical learning. 

Each section documents what I have learned, the practical tasks I completed, and the troubleshooting process I used.
